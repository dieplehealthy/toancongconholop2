# Hành trình Toán 2 – Phiêu lưu 14 hòn đảo

Trò chơi luyện Toán lớp 2 (tập 1) bám theo sách *Toán 2 – Kết nối tri thức với cuộc sống*.
Không cần cài đặt hay máy chủ: chỉ gồm các file `index.html`, `style.css`, `questions.js`, `app.js`.

## Đăng lên GitHub Pages
1. Vào https://github.com → **New repository** → đặt tên (ví dụ `toan-lop-2`) → **Public** → Create.
2. Bấm **uploading an existing file**, kéo thả **cả 4 file** (`index.html`, `style.css`, `questions.js`, `app.js`) rồi **Commit changes**.
3. Vào **Settings → Pages** → mục *Build and deployment*: Source = **Deploy from a branch**, Branch = **main**, thư mục **/(root)** → Save.
4. Chờ 1–2 phút, link có dạng `https://<tên-github>.github.io/toan-lop-2/`.
